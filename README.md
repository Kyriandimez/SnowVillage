# SnowVillage website
Plain HTML/CSS/JS, no build step. Open `index.html` (or run `python3 -m http.server`).

- Routes are hash-based: `#commercial-chillers`, `#commercial-freezers`, `#chest-freezers`, `#solar-power-solutions`.
- `script.js` top: `CFG` (WhatsApp numbers, phone, TikTok/Instagram URLs) and `CATS` (product data; specs marked "Pending confirmation" are not sent in WhatsApp messages).
- `assets/snowvillage-wordmark.svg` is the shared logo shown in the navigation, hero, and footer.
- Product and feature photos in `assets/` can be replaced with real images (same filenames or update `CATS`/`index.html`).
